Research design

Y: RoA = ib / at
X: R&D intensity = xrd / at
H1: R&D intensity negatively affects RoA (IFRS expensing)
H2: Firm size positively moderates R&D → RoA
Interaction: rd_intensity × ln_at

Variable Construction — Full Runnable Block

Copy and paste the entire block into your Python shell:

import pandas as pd, numpy as np, math, os
from pathlib import Path

os.chdir("C:/path/to/your/sme-internationalization")  # adapt your path

df = pd.read_parquet("data/processed/panel_clean.parquet")

# Data quality + size filters
df = df[(df["at"] > 0.1) & (df["sale"] > 0) & (df["seq"] > 0)].copy()
df = df[df["at"] >= 1].copy()              # remove micro-firms (log(at) < 0)
df = df[(df["emp"] < 0.25) | (df["at"] <= 43)].copy()  # EU SME filter

# Y: Return on Assets
df["roa"]          = df["ib"] / df["at"]

# X: R&D intensity (missing xrd = firm did not report R&D = 0)
df["rd_intensity"] = df["xrd"].fillna(0) / df["at"]

# Moderator + control: firm size
df["ln_at"]        = df["at"].apply(lambda x: math.log(x) if x > 0 else np.nan)

# H2 interaction
df["rd_x_size"]    = df["rd_intensity"] * df["ln_at"]

# Controls
df["leverage"]       = df["dltt"].fillna(0) / df["at"]
df["capx_intensity"] = df["capx"].fillna(0) / df["at"]
df["cash_ratio"]     = df["che"].fillna(0)  / df["at"]

print(f"Sample: {len(df):,} rows | {df['gvkey'].nunique():,} firms")
print(f"R&D firms: {(df['rd_intensity']>0).sum():,} "
      f"({(df['rd_intensity']>0).mean()*100:.1f}%)")

Winsorizing — Why & How

The problem: extreme outliers

A single data entry error (RoA = 500%) pulls regression coefficients dramatically and inflates standard errors.

Standard practice: winsorize at 1%–99%

Winsorizing ≠ dropping. Values beyond the threshold are replaced with the threshold value, not removed.

Do NOT winsorize ln_at — log-transforming already removes skew. Winsorizing size would distort the distribution.

Recompute interactions after winsorizing inputs — otherwise rd_x_size uses the un-winsorized values.

# Run AFTER the variable construction block above

def winsorize(series, lower=0.01, upper=0.99):
    lo = series.quantile(lower)
    hi = series.quantile(upper)
    return series.clip(lo, hi)

for col in ["roa", "rd_intensity",
            "leverage", "capx_intensity",
            "cash_ratio"]:
    df[col] = winsorize(df[col])
    print(f"{col}: "
          f"[{df[col].min():.3f}, {df[col].max():.3f}]")

# Recompute interaction after winsorizing inputs
df["rd_x_size"] = df["rd_intensity"] * df["ln_at"]

# Min 3 observations per firm for FE estimation
obs   = df.groupby("gvkey")["fyear"].count()
valid = obs[obs >= 3].index
df    = df[df["gvkey"].isin(valid)].copy()
print(f"Final: {len(df):,} rows | "
      f"{df['gvkey'].nunique():,} firms")

Regression Fundamentals — OLS

\[Y_i = \alpha + \beta_1 X_{1i} + \cdots + \beta_k X_{ki} + \varepsilon_i\]

import statsmodels.formula.api as smf

# Pooled OLS — baseline (run after variable construction + winsorize)
res_ols = smf.ols(
    "roa ~ rd_intensity + ln_at + leverage + "
    "capx_intensity + cash_ratio",
    data=df
).fit(cov_type="HC3")   # HC3 = heteroskedasticity-robust SEs

print(res_ols.summary().tables[1])
print(f"R² = {res_ols.rsquared:.3f}")

Reading the output:

Column Meaning
coef β — direction and magnitude
std err Uncertainty around the estimate
t coef / std err
P>\|t\| p-value — prob of seeing this if β = 0
R² Share of variance in Y explained

Stars: *** p<0.01    ** p<0.05    * p<0.10

The Problem with OLS for Panel Data

Omitted variable bias:

True model: \(Y_{it} = \alpha + \beta X_{it} + \gamma Z_i + \varepsilon_{it}\)

If \(Z_i\) (unobserved, time-invariant) correlates with \(X_{it}\), OLS estimate of \(\beta\) is biased.

Our example:

Innovation culture → more R&D AND better long-run performance. OLS conflates culture’s effect with R&D’s effect.

Evidence:

OLS β = -0.796
FE β = -0.535
Difference = 49%

The fixed effects solution:

\[Y_{it} = \beta X_{it} + \gamma Z_{it} + \mu_i + \lambda_t + \varepsilon_{it}\]

  • \(\mu_i\) = firm FE — absorbs time-invariant heterogeneity
  • \(\lambda_t\) = year FE — absorbs common shocks
from linearmodels.panel import PanelOLS

df_panel = df.dropna(
    subset=["roa","rd_intensity","ln_at",
            "leverage","capx_intensity",
            "cash_ratio","rd_x_size"]
).set_index(["gvkey","fyear"])

res_fe = PanelOLS.from_formula(
    "roa ~ rd_intensity + ln_at + leverage + "
    "capx_intensity + cash_ratio + "
    "EntityEffects + TimeEffects",
    data=df_panel
).fit(cov_type="clustered",
      cluster_entity=True)

print(res_fe.summary.tables[1])

Testing H2 — Interaction Term

# H2: firm size positively moderates the R&D -> RoA relationship
# rd_x_size = rd_intensity * ln_at  (already constructed above)

res_h2 = PanelOLS.from_formula(
    "roa ~ rd_intensity + rd_x_size + "
    "ln_at + leverage + capx_intensity + cash_ratio + "
    "EntityEffects + TimeEffects",
    data=df_panel
).fit(cov_type="clustered", cluster_entity=True)

b_rd  = res_h2.params["rd_intensity"]
b_int = res_h2.params["rd_x_size"]
p_int = res_h2.pvalues["rd_x_size"]

print(f"beta(rd_intensity) = {b_rd:.4f}")
print(f"beta(rd_x_size)    = {b_int:.4f}  (p = {p_int:.3f})")

if b_int > 0 and p_int < 0.10:
    print("H2 SUPPORTED: larger SMEs benefit more from R&D")
else:
    print("H2 NOT SUPPORTED")

Our results: β(rd_x_size) = 0.038, p = 0.559 → H2 not supported. Direction is positive (consistent with H2) but not statistically distinguishable from zero.

Six Panel Regression Methods

Method When to use Key assumption Python
Pooled OLS Baseline only Obs. independent smf.ols()
Random Effects Heterogeneity uncorrelated with X Strict exogeneity RandomEffects
Fixed Effects Heterogeneity may correlate with X Within-firm variation PanelOLS + EntityEffects
Two-way FE FE + common time shocks — + TimeEffects
First Differences Non-stationary panels No serial correlation FirstDifferenceOLS
Between Effects Cross-section only Obs. independent BetweenOLS

Hausman comparison — FE vs RE:

from linearmodels.panel import RandomEffects

res_re = RandomEffects.from_formula(

    data=df_panel).fit()

diff = abs(res_fe.params["rd_intensity"] - res_re.params["rd_intensity"])
print(f"FE: {res_fe.params['rd_intensity']:.4f} | "
      f"RE: {res_re.params['rd_intensity']:.4f} | diff: {diff:.4f}")
# Our result: diff = 0.06 -> prefer FE

Limited Dependent Variable Models

When Y is not continuous:

DV type Example Model Command
Binary (0/1) Entered export market Logit / Probit smf.logit()
Count Number of markets Poisson smf.poisson()
Censored Export share (many zeros) Tobit statsmodels
Ordered Survey 1–5 Ordered logit statsmodels.MNLogit 
# Example: binary DV — did the firm increase R&D? (0/1)
df["rd_increase"] = (
    df.groupby("gvkey")["rd_intensity"].diff() > 0
).astype(int)

res_logit = smf.logit(
    "rd_increase ~ ln_at + leverage + cash_ratio",
    data=df.dropna()
).fit()

# Coefficients are log-odds — convert to odds ratios:
import numpy as np
print(np.exp(res_logit.params))   # odds ratios

For this project (continuous RoA) → linear panel FE. Logit/Probit relevant if your DV is a binary decision variable.
