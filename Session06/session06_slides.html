df[df["loc"] == "AUT"]                  # Austrian firms only

Pandas Essentials — Groupby & Merge

# Group by — descriptive stats per country
df.groupby("loc")["at"].mean()
df.groupby(["loc", "fyear"])["ib"].agg(["mean", "std", "count"])

# Create new columns (variable construction)
df["roa"]          = df["ib"] / df["at"]
df["rd_intensity"] = df["xrd"].fillna(0) / df["at"]
df["leverage"]     = (df["dltt"] + df["dlc"]) / df["seq"]
df["ln_at"]        = df["at"].apply(lambda x: pd.NA if x <= 0 else __import__('math').log(x))
df["age"]          = df["fyear"] - df["inco"]

# Sort
df = df.sort_values(["gvkey", "fyear"]).reset_index(drop=True)

# Lag a variable (for growth rates)
df["sale_lag"] = df.groupby("gvkey")["sale"].shift(1)
df["sale_growth"] = (df["sale"] - df["sale_lag"]) / df["sale_lag"]

pandas vs Polars: For large datasets, Polars is faster. But linearmodels (our regression package) expects pandas DataFrames — so we stay with pandas for this project.

Winsorizing — Why & How

The problem: extreme outliers

A single data entry error or genuine outlier (RoA = 500%) can:

  • Pull regression coefficients dramatically
  • Inflate standard errors
  • Make results non-representative

Standard practice: winsorize at 1%–99% (sometimes 5%–95% for very noisy variables)

Winsorizing ≠ dropping. Values beyond the threshold are replaced with the threshold value, not removed. You keep the same number of observations.

def winsorize(series, lower=0.01, upper=0.99):
    """Replace extreme values with percentile bounds."""
    lo = series.quantile(lower)
    hi = series.quantile(upper)
    return series.clip(lo, hi)

# Apply to all continuous research variables
for col in ["roa", "rd_intensity",
            "leverage", "capx_intensity"]:
    df[col] = winsorize(df[col])

Descriptive Statistics — What to Look For

Summary statistics table

vars = ["roa", "rd_intensity",
        "leverage", "ln_at", "age"]

summary = df[vars].describe(
    percentiles=[0.25, 0.5, 0.75]
).T.round(3)

What to check:

  • Mean vs median: large gap = skew → log-transform?
  • Std dev: larger than mean = high variance → winsorize?
  • Min/max: impossible values? (negative assets, RoA < -1)
  • Count: fewer than total rows = missing values

If count for your X variable is much less than total rows, you have a missing data problem. Check df["xrd"].isna().sum().

Correlation matrix

import seaborn as sns
import numpy as np

corr = df[vars].corr().round(2)
mask = np.triu(np.ones_like(corr, dtype=bool))
sns.heatmap(corr, mask=mask, annot=True,
            cmap="RdYlBu_r", center=0)

What to check:

  • X vs Y: is there a raw correlation with your DV?
  • X vs controls: multicollinearity if r > 0.8
  • Between controls: if two controls correlate > 0.8, consider dropping one

Rule of thumb: r > 0.8 between two independent variables → multicollinearity risk → check Variance Inflation Factor (VIF)

Regression Fundamentals — OLS Recap

The OLS model:

\[Y_i = \alpha + \beta_1 X_{1i} + \beta_2 X_{2i} + \cdots + \beta_k X_{ki} + \varepsilon_i\]

  • \(Y_i\) — dependent variable (e.g. RoA)
  • \(X_{ki}\) — independent variables (R&D intensity, controls)
  • \(\beta_k\) — coefficients: effect of a 1-unit change in \(X_k\) on \(Y\), holding all other variables constant (ceteris paribus)
  • \(\varepsilon_i\) — error term (everything not captured by the model)

OLS minimizes the sum of squared residuals:

\[\hat{\beta} = \arg\min_\beta \sum_{i=1}^n (Y_i - \hat{Y}_i)^2\]

Key OLS assumptions (Gauss-Markov):

  1. Linearity in parameters
  2. Random sampling
  3. No perfect multicollinearity
  4. Zero conditional mean of errors: \(E[\varepsilon | X] = 0\)
  5. Homoskedasticity: \(Var(\varepsilon | X) = \sigma^2\)

Reading OLS Output

import statsmodels.formula.api as smf

model = smf.ols("roa ~ rd_intensity + ln_at + leverage + age", data=df)
result = model.fit()
print(result.summary())

What to read:

Output element What it means
coef Estimated β — direction and magnitude of effect
std err Uncertainty around the estimate
t coef / std err — how many standard errors from zero
P>|t| p-value: probability of seeing this result if β = 0
[0.025, 0.975] 95% confidence interval — should not include 0
R² Share of variance in Y explained by the model
F-statistic Joint significance of all variables

Stars: *** p<0.01    ** p<0.05    * p<0.10    Conventional thresholds — arbitrary but universal.

The Problem with OLS for Panel Data

OLS assumes observations are independent. In panel data they are not:

  • Firm A in 2018 and 2019 are correlated (same firm)
  • Firm A and Firm B may differ systematically in ways we don’t observe (management quality, culture, location advantages)

Omitted variable bias:

\[\text{True model: } Y_{it} = \alpha + \beta X_{it} + \gamma Z_i + \varepsilon_{it}\]

If \(Z_i\) (unobserved, time-invariant) correlates with \(X_{it}\), OLS estimate of \(\beta\) is biased.

Example: innovative firms (high R&D) may also have better management — we can’t measure management, but it affects RoA.

Visualizing the problem:

         Firm A (high mgmt quality)
RoA ↑     ●  ●  ●
          ●  ●
         Firm B (low mgmt quality)
          ●  ●
          ●  ●  ●

         ───────────────→ R&D intensity

OLS sees a positive slope across all dots.
But within each firm the slope may be flat or negative.

Fixed effects solution: control for all time-invariant firm characteristics by including a dummy for each firm (\(\mu_i\)).

\[Y_{it} = \beta X_{it} + \gamma Z_{it} + \mu_i + \lambda_t + \varepsilon_{it}\]

The Firm-Year Panel Structure

\[Y_{it} = \beta X_{it} + \gamma Z_{it} + \mu_i + \lambda_t + \varepsilon_{it}\]

Two dimensions:

  • \(i\) = firm (entity dimension)
  • \(t\) = fiscal year (time dimension)

Two types of fixed effects:

  • \(\mu_i\) = firm fixed effects — absorb all time-invariant firm characteristics (country, industry, founder quality, culture)
  • \(\lambda_t\) = year fixed effects — absorb common shocks affecting all firms in a given year (financial crisis, COVID, policy changes)

Together: two-way fixed effects (TWFE) — the standard in empirical IB research

from linearmodels.panel import PanelOLS

# Requires MultiIndex: (entity, time)
df_panel = df.set_index(["gvkey", "fyear"])

model = PanelOLS.from_formula(
    "roa ~ rd_intensity + ln_at + "
    "leverage + age + "
    "EntityEffects + TimeEffects",
    data=df_panel
)

result = model.fit(
    cov_type="clustered",
    cluster_entity=True    # cluster SEs at firm level
)
print(result.summary)

Clustered standard errors: firms have correlated errors over time. Clustering at the firm level corrects for this — otherwise SEs are too small and t-stats too large.

Six Panel Regression Methods

Method When to use Key assumption In Python
Pooled OLS Baseline only — ignores panel structure Obs. independent smf.ols()
Random Effects (RE) Unobserved heterogeneity uncorrelated with X Strict exogeneity RandomEffects
Fixed Effects (FE) Unobserved heterogeneity may correlate with X Within-firm variation in X PanelOLS + EntityEffects
Two-way FE (TWFE) FE + common time shocks — + TimeEffects
First Differences (FD) Non-stationary panels, unit roots Errors not serially correlated FirstDifferenceOLS
Between Effects (BE) Cross-sectional variation only Obs. independent across firms BetweenOLS

How to choose:

  1. Always start with TWFE — it is the most conservative and credible
  2. Hausman test: if RE is consistent, use RE (more efficient); if not, use FE
  3. FD if you suspect non-stationarity (trending variables like assets)
  4. BE only if you have a specific cross-sectional research question

For this course: TWFE with clustered SEs is the standard. Always report it. Add RE as a robustness check.

Hausman Test — FE or RE?

from linearmodels.panel import RandomEffects, PanelOLS
from linearmodels.panel.model import compare

# Run both
fe = PanelOLS.from_formula(
    "roa ~ rd_intensity + ln_at + leverage + EntityEffects",
    data=df_panel).fit()

re = RandomEffects.from_formula(
    "roa ~ rd_intensity + ln_at + leverage",
    data=df_panel).fit()

Logic of the Hausman test:

  • H₀: RE is consistent (unobserved effects uncorrelated with X) → prefer RE (more efficient)
  • H₁: RE is inconsistent (correlation exists) → use FE

\[H = (\hat{\beta}_{FE} - \hat{\beta}_{RE})' [\text{Var}(\hat{\beta}_{FE}) - \text{Var}(\hat{\beta}_{RE})]^{-1} (\hat{\beta}_{FE} - \hat{\beta}_{RE}) \sim \chi^2_k\]

In practice for IB research: most scholars default to FE because the assumption that firm-level unobservables are uncorrelated with R&D or internationalization is hard to defend theoretically. Use the Hausman test as confirmation, not as the primary decision criterion.

Limited Dependent Variable Models

When your Y is not continuous:

DV type Example Model Command
Binary (0/1) Firm entered foreign market: yes/no Logit / Probit smf.logit() / smf.probit()
Count (0,1,2,…) Number of export markets Poisson / Neg. Binomial smf.poisson()
Censored Export share (many zeros) Tobit statsmodels.tobit
Ordered Survey: agree/neutral/disagree Ordered logit statsmodels.MNLogit

Logit interpretation:

\[\ln\left(\frac{p}{1-p}\right) = \alpha + \beta X\]

Coefficients are log-odds — not directly interpretable. Convert to odds ratios: \(e^\beta\)

For most SME performance research (RoA, RoE, sales growth) — continuous DV — you will use linear panel FE. Logit/Probit are relevant if your DV is “did the firm internationalize?” (binary) or “how many markets did it enter?” (count).

Deciding Which Model to Use

Is your DV continuous?
├── YES → Does your data have a panel structure (firm × year)?
│         ├── YES → Use TWFE (PanelOLS + EntityEffects + TimeEffects)
│         │         └── Run Hausman test to confirm FE > RE
│         └── NO  → Use OLS (smf.ols)
│
└── NO  → What type?
          ├── Binary (0/1)    → Logit or Probit
          ├── Count (0,1,2..) → Poisson or Negative Binomial
          ├── Censored (many zeros) → Tobit
          └── Ordered categories → Ordered Logit

For this course: your DV (RoA, leverage ratio, sales growth) is continuous and your data is a firm-year panel → always use TWFE as your main specification.
