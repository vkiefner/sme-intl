Getting Help in Python

The interactive shell is your best friend

Open the Python shell: in your terminal, type python and press Enter.

# Get help on any object, function or module
help(str)          # full docs for strings
help(len)          # docs for the len() function
help(list.append)  # docs for a specific method
# See all available methods on an object
dir("hello")       # all string methods
dir([1, 2, 3])     # all list methods
dir(42)            # all int methods
# Quick type check
type(42)           # <class 'int'>
type("hello")      # <class 'str'>
type([1, 2])       # <class 'list'>
type({"a": 1})     # <class 'dict'>

💡 help() and dir() work on everything in Python — objects, functions, modules, packages. Use them constantly.

Core Data Types

# Integer
x = 42
type(x)          # <class 'int'>

# Float
pi = 3.14159
type(pi)         # <class 'float'>

# String
name = "SME"
type(name)       # <class 'str'>

# Boolean
flag = True
type(flag)       # <class 'bool'>

# None (missing value)
result = None
type(result)     # <class 'NoneType'>
# Type conversion (casting)
int("42")        # 42
float("3.14")    # 3.14
str(42)          # "42"
bool(0)          # False
bool(1)          # True
bool("")         # False  ← empty string
bool("text")     # True

In research code, always check types when loading data — a column of numbers read from CSV often comes in as str, not int or float. Use df.dtypes in pandas to verify.

Variables & Assignment

# Assignment — no type declaration needed
firm_name   = "Bosch"
employees   = 429000
revenue     = 91.6          # in billion EUR
is_sme      = False

# Multiple assignment
x = y = z = 0

# Swap values (Python-style, no temp variable needed)
a, b = 1, 2
a, b = b, a                 # a=2, b=1

# Augmented assignment
count  = 0
count += 1                  # count = count + 1
count *= 2                  # count = count * 2

Naming conventions (follow these in your scripts):

  • Variables and functions: snake_case → firm_size, pull_data()
  • Constants: UPPER_CASE → WRDS_USERNAME, START_YEAR
  • Never use reserved words: list, str, type, id, input

Common Syntax Structures

Conditionals

doi = 0.35

if doi > 0.5:
    print("High internationalization")
elif doi > 0.2:
    print("Medium internationalization")
else:
    print("Low internationalization")

For loops

countries = ["AUT", "DEU", "CHE"]

for country in countries:
    print(f"Processing: {country}")

# Loop with index
for i, country in enumerate(countries):
    print(f"{i}: {country}")

While loops

attempts = 0
max_attempts = 3

while attempts < max_attempts:
    print(f"Attempt {attempts + 1}")
    attempts += 1

List comprehensions

# Traditional loop
squares = []
for n in range(5):
    squares.append(n ** 2)

# List comprehension (Pythonic)
squares = [n ** 2 for n in range(5)]
# [0, 1, 4, 9, 16]

# With condition
even = [n for n in range(10) if n % 2 == 0]
# [0, 2, 4, 6, 8]

Functions

# Define a function
def winsorize(value, lower, upper):
    """Clip a value between lower and upper bounds."""
    return max(lower, min(upper, value))

# Call it
winsorize(150, 0, 100)    # returns 100
winsorize(-5,  0, 100)    # returns 0
winsorize(42,  0, 100)    # returns 42
# Default arguments
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

greet("Valentin")            # "Hello, Valentin!"
greet("Valentin", "Hi")      # "Hi, Valentin!"

# Return multiple values (returns a tuple)
def summary(values):
    return min(values), max(values), sum(values) / len(values)

lo, hi, avg = summary([1, 2, 3, 4, 5])

Always write a docstring (the """...""" line). It’s what help() shows. One sentence describing what the function does and what it returns.

Math Functions

import math

math.sqrt(16)       # 4.0
math.log(math.e)    # 1.0  (natural log)
math.log(100, 10)   # 2.0  (log base 10)
math.log(2)         # 0.693 (natural log of 2)
math.exp(1)         # 2.718 (e^1)
math.ceil(3.2)      # 4
math.floor(3.9)     # 3
math.pi             # 3.14159...
math.inf            # infinity
# Python operators
2 ** 3              # 8   (exponentiation)
10 % 3              # 1   (modulo — remainder)
10 // 3             # 3   (floor division)
abs(-5)             # 5   (absolute value)
round(3.14159, 2)   # 3.14

In research: math.log() is used constantly — log of firm size (log(total_assets)) is a standard control variable. math.sqrt() appears in standard error calculations. You will mostly use these through numpy and pandas, but knowing the base Python versions helps you debug.

Strings & String Methods

s = "  SME Internationalization  "

# Common methods
s.strip()           # remove whitespace
s.lower()           # "  sme intern..."
s.upper()           # "  SME INTERN..."
s.replace("SME", "Firm")
s.split(" ")        # list of words
" ".join(["a","b"]) # "a b"
s.startswith("SME") # False (leading space)
s.strip().startswith("SME")  # True
len(s)              # 30

# Check content
"SME" in s          # True
s.isdigit()         # False
"42".isdigit()      # True
# f-strings (use these — fastest & clearest)
name  = "Bosch"
sales = 91.6
print(f"{name} has €{sales:.1f}bn in sales")
# Bosch has €91.6bn in sales

# Format numbers
f"{1234567:.2f}"    # "1234567.00"
f"{1234567:,.0f}"   # "1,234,567"
f"{0.0351:.1%}"     # "3.5%"

# Slice a string
s = "AUT2015"
s[:3]               # "AUT"  (country)
s[3:]               # "2015" (year)
s[3:7]              # "2015"

Useful in data cleaning: .strip() removes invisible whitespace that causes merge failures. Always strip string columns before joining datasets.

Lists

# Create
firms = ["Bosch", "Siemens", "ABB", "Voith"]

# Access
firms[0]            # "Bosch"   (first)
firms[-1]           # "Voith"   (last)
firms[1:3]          # ["Siemens", "ABB"]

# Modify
firms.append("Trumpf")      # add to end
firms.insert(0, "BMW")      # insert at index
firms.remove("ABB")         # remove by value
firms.pop()                 # remove & return last
firms.sort()                # sort in-place
firms.reverse()             # reverse in-place

# Check
"Bosch" in firms            # True
len(firms)                  # count
firms.count("Bosch")        # how many times
firms.index("Siemens")      # position

Lists are mutable — you can change them after creation. This is unlike tuples (next slide).

Tuples & Dictionaries

Tuples — immutable lists

# Parentheses (optional but conventional)
coords = (48.2, 16.4)       # lat, lon Vienna
year_range = (2015, 2024)

# Access same as list
coords[0]           # 48.2

# Cannot modify
coords[0] = 0       # ← TypeError!

# Unpack
lat, lon = coords

# Common use: function return values
def get_range(data):
    return min(data), max(data)  # returns tuple

lo, hi = get_range([1, 5, 3])

Dictionaries — key-value pairs

firm = {
    "name":      "Bosch",
    "country":   "DEU",
    "employees": 429000,
    "revenue":   91.6,
}

# Access
firm["name"]                # "Bosch"
firm.get("founded", "N/A")  # safe access

# Modify
firm["revenue"] = 95.0
firm["listed"] = False

# Iterate
for key, value in firm.items():
    print(f"{key}: {value}")

firm.keys()     # dict_keys([...])
firm.values()   # dict_values([...])
"name" in firm  # True

In pandas: a DataFrame is essentially a dict of lists — each column name is a key, each column is a list of values. Understanding dicts makes pandas much more intuitive.

File Methods

# Write a text file
with open("output/log.txt", "w") as f:
    f.write("Run started\n")
    f.write("Rows pulled: 45,231\n")

# Append to existing file
with open("output/log.txt", "a") as f:
    f.write("Run completed\n")

# Read a file
with open("output/log.txt", "r") as f:
    content = f.read()          # entire file as string
    lines   = f.readlines()     # list of lines

# Check if a file or folder exists
from pathlib import Path

Path("data/raw").exists()           # True / False
Path("data/raw").mkdir(parents=True, exist_ok=True)  # create folder
list(Path("data/raw").iterdir())    # list contents

Always use with open(...) — it automatically closes the file even if an error occurs. Using open() without with risks data corruption if your script crashes mid-write.

Pathlib — Working with File Paths

from pathlib import Path

# Build paths (works on Windows AND Mac/Linux)
base    = Path("data")
raw     = base / "raw"           # data/raw
out     = Path("output") / "tables" / "summary.csv"

# Never do this — breaks on Windows:
# raw = "data/raw"  ← fragile string

# Useful methods
raw.exists()            # does it exist?
raw.mkdir(parents=True, exist_ok=True)   # create folder
raw.suffix              # ".csv"
raw.stem                # "summary" (filename without extension)
raw.parent              # Path("output/tables")
list(raw.iterdir())     # list all files

# Find the most recent file in a folder
files = sorted(Path("data/raw").iterdir())
latest = files[-1]      # last = most recent (sorted by name)

Key rule: always use pathlib.Path for file paths. It handles \ vs / automatically — your scripts will work identically on Windows and Mac.

Now: Live Code — 01_pull_data.py

What this script does

  1. Loads WRDS credentials from .env
  2. Connects to WRDS
  3. Pulls all Compustat Global annual variables — fiscal years 2015–2024, all geographies
  4. Chunks the result by fiscal year
  5. Saves each chunk as a .parquet file inside a timestamped folder under data/raw/

Why parquet?

  • Columnar format → reads only the columns you need
  • 5–10× smaller than CSV
  • Preserves data types (no silent string conversion)
  • pandas.read_parquet() is faster than read_csv()

Folder output:

data/raw/
└── 2026-05-13_14-32-05/
    ├── fyear_2015.parquet
    ├── fyear_2016.parquet
    ├── fyear_2017.parquet
    ├── ...
    └── fyear_2024.parquet

Each run creates a new timestamped folder — you always keep a record of every pull. The clean script automatically picks the most recent folder.

Now: Live Code — 02_clean.py

What this script does

  1. Finds the most recent timestamped folder in data/raw/
  2. Reads all parquet chunks and concatenates into one DataFrame
  3. Standardizes column names (lowercase, no spaces)
  4. Drops full duplicates
  5. Drops observations missing both gvkey and fyear (panel identifiers)
  6. Converts numeric columns to correct dtype
  7. Sorts by gvkey, fyear
  8. Saves as data/processed/panel_clean.parquet

Result: a firm-year panel ready for analysis — one row per firm per year, all Compustat variables as columns.

Panel structure:

gvkey  fyear  at    sale   ib   ...
──────────────────────────────────
001000  2015  12.3   8.1  0.4
001000  2016  13.1   8.9  0.5
001000  2017  14.0   9.2  0.6
001001  2015   2.1   1.4  0.1
001001  2016   2.4   1.5  0.2
...

gvkey = firm identifier
fyear = fiscal year
Together they form the unique key of the panel.
