## Example Project — R&D Intensity and Firm Performance

The `sme-internationalization/` folder contains the reference implementation students use as a model. It examines the short-run effect of R&D intensity on return on assets (RoA) among European EUR-reporting SMEs over 2015–2024.

**Research question:** Does R&D intensity affect firm performance among European SMEs, and does firm size moderate this relationship?

**Hypotheses:**
- **H1:** R&D intensity negatively affects current-period RoA, reflecting the immediate expensing effect under IFRS. *(β(rd\_intensity) < 0)*
- **H2:** Firm size positively moderates the R&D intensity–RoA relationship. *(β(rd\_intensity × ln\_at) > 0)*

**Main results:**

| Model | β(R&D intensity) | β(R&D × Size) | Firm FE | Year FE |
|-------|-----------------|---------------|---------|---------|
| (1) Pooled OLS | −0.796*** | — | No | No |
| (2) TWFE | −0.535*** | — | Yes | Yes |
| (3) TWFE + H2 | −0.635*** | 0.038 (n.s.) | Yes | Yes |

H1 is supported: R&D investment significantly reduces current-period accounting profitability, consistent with the IFRS expensing mechanism. The OLS estimate overstates the effect by 49% relative to the panel FE estimate, illustrating the importance of controlling for firm-level heterogeneity. H2 is not supported at conventional significance levels.

## Reproducing the Example Project

```bash
# 1. Clone the repository
git clone https://github.com/vkiefner/sme-intl
cd sme-intl/sme-internationalization

# 2. Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate        # Mac / Linux
# .venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Register the Jupyter kernel (needed for Quarto rendering)
python -m ipykernel install --user --name=sme-venv --display-name "SME Project (.venv)"

# 5. Set WRDS credentials
cp .env.example .env
# Open .env and add: WRDS_USERNAME=your_username

# 6. Run the full pipeline (pulls data, cleans, analyses, renders PDF)
task all
```

The full pipeline takes 10–30 minutes on first run (WRDS data pull). Subsequent runs skip the pull step if data already exists.

**Output:** `research_note.pdf` in the project root.

## Data

| Item | Detail |
|------|--------|
| Source | WRDS / Compustat Global (`comp_global_daily.g_funda`) |
| Currency filter | EUR only (`curcd = 'EUR'`) |
| SME filter | ≤250 employees OR ≤€43m total assets (EU definition) |
| Quality filters | `at > 0.1`, `sale > 0`, `seq > 0`, `at ≥ 1` |
| Period | Fiscal years 2015–2024 |
| datafmt | `HIST_STD` (Compustat Global standard) |

## Assessment (Student Submissions)

Students submit:
1. `research_note.pdf` via Canvas — rendered from their own `research_note.qmd`
2. GitHub repository link — printed on the title page of the PDF

The examiner clones the student's repository and runs `task all` on a clean machine. The pipeline must complete without errors and produce `research_note.pdf`.

**Assessment criteria:**

| Criterion | Weight |
|-----------|--------|
| GitHub reproducibility (`task all` runs, correct structure) | 25% |
| Results quality and interpretation | 35% |
| Method justification (FE, SEs, winsorizing) | 20% |
| Hypothesis development (theory → mechanism → H) | 15% |
| Originality (own RQ, variables, interpretation) | 5% |
